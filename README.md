# cgs-3ds

[Card Game Simulator](https://www.cardgamesimulator.com/) for the Nintendo 3DS family
(developed on a New Nintendo 2DS XL), as native homebrew.

- `app/` – 3DS client (C/C++, devkitPro: devkitARM, libctru, citro2d) *(planned)*
- `tools/converter/` – converts a CGS game into a 3DS game pack (C#) *(planned)*
- `protocol/` – CGS Table Protocol (CTP) for cross-platform multiplayer *(planned)*

See [docs/PLAN.md](docs/PLAN.md) for the plan and roadmap.
